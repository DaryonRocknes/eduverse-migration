# Outil de migration EDUVERSE (PostgreSQL → MySQL)

Outil Webtinix qui copie une base EDUVERSE PostgreSQL vers MySQL/MariaDB (XAMPP),
en un clic, avec vérification des comptages.

- Mode d'emploi : [LISEZ-MOI.txt](LISEZ-MOI.txt)
- Windows : [GUIDE-COMPLET-WINDOWS.txt](GUIDE-COMPLET-WINDOWS.txt) et
  [FABRIQUER-LE-EXE-WINDOWS.txt](FABRIQUER-LE-EXE-WINDOWS.txt)
- Les exécutables Linux et Windows sont dans les *Releases* du dépôt.

⚠ `config.ini` est publié **sans mot de passe**. Ne jamais committer une
configuration remplie : utiliser une copie locale `config.local.ini` (ignorée par git).
